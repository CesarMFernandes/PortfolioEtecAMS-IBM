Diagrama de Sequencia - Snack Paradise

Este é o diagrama de sequencia do grupo Snack Paradise, do 2° AMS, que explica a relação temporal entre os objetos do sistema, como o usuário, frontend, backend e motoboy.

O diagrama começa a partir da interação inicial do usuário com o site, fazendo o login ou se cadastrando, e termina assim que o usuário opta por fazer uma avaliação sobre o serviço prestado.
