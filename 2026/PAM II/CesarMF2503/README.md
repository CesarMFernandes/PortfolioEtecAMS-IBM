Como utilizar o app:<br>
1- Abra a pasta no Android Studio<br>
2- Rode o app<br>
3- Coloque seu nomo na caixa de texto<br>
4- Abra o logcat<br>
5- O registro dos botões que você apertou e o nome que você digitou aparecerá no logcat<br>
